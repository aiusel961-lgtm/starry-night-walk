# 星月之间 · A Starry Night Walk

一个可离线运行的浏览器飞行漫游场景：从石巷、教堂和丝柏俯瞰三个出发点探索星空下的山谷村庄。

## 运行

直接双击 `启动-独显优先.cmd`，或打开 `index.html`。首次载入请保留旁边的 `scene` 文件夹。

更完整的操作说明、镜头和制作记录见 [使用说明.md](使用说明.md)。

## 内容

- `index.html`：浏览器中的漫游入口
- `scene/`：Blender 场景、模型、贴图和运行时脚本
- `tools/`：场景生成、检查和对照工具
- `场景对照分析/`：镜头对照与优化记录

大型 Blender 和模型资源使用 Git LFS 保存。
